# Stripe business description for Thido

## Recommended business type

**Software as a Service (SaaS) / productivity software**

Thido sells access to a web-based, AI-assisted document creation and editing
service. Customers use the software to draft, edit, organise, comment on, and
share documents. AI features help customers create first drafts, answer
questions about selected text, and suggest or apply revisions.

## Short description for Stripe

> Thido is a subscription-based productivity software service that helps users
> create, edit, organise, and share documents, with optional AI-assisted
> drafting, comments, and revisions.

## More detailed description

> Thido provides paid subscriptions to a web-based document creation and
> editing platform. Customers can write and format documents, collaborate by
> sharing documents and comments, and use AI-assisted tools to generate drafts
> and request revisions. The service is delivered digitally through thido.ai;
> customers receive account access online and no physical goods are sold or
> shipped.

## Other Stripe registration fields

- **Product or service:** Subscription access to online document productivity
  software with AI-assisted writing and editing features.
- **How customers receive it:** Immediate digital access through a Thido user
  account after signing up or subscribing.
- **Customers:** Individuals and professionals who create, review, or share
  documents.
- **Business model:** Free beta access with optional recurring paid software
  subscriptions.
- **Website:** `https://thido.ai`

Use only pricing, billing intervals, trials, and paid-plan features that have
been finalized and are displayed to the customer before checkout.
